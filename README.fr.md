## 🛠️ Technologies

**HTML5, CSS3 et JavaScript natif** — sans framework ni étape de build — avec Google Fonts (DM Serif Display, DM Sans, JetBrains Mono) et animations d'apparition au défilement.

## 📁 Structure

```
portfolio/
├── index.html   # Structure et contenu de la page
├── style.css    # Design, mise en page, règles responsive
├── script.js    # Interactions et animations
└── assets/      # Images et CV
```

## 🚀 Lancer en local

```bash
git clone https://github.com/ayakhama3/portfolio.git
cd portfolio

# Option 1 : ouvrir index.html dans le navigateur
# Option 2 : le servir en local
python -m http.server 8000     # puis ouvrir http://localhost:8000
```
