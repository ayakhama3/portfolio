# 🌐 Portfolio – Aya Khama

Site portfolio personnel d'**Aya Khama**, étudiante ingénieure Data Science & IA (EMSI, Rabat, diplôme 2027) : projets, expérience, formation et compétences.

## ✨ Fonctionnalités
- Site statique responsive (HTML, CSS, JavaScript), sans framework
- Thème clair / sombre avec mémorisation du choix
- Sections projets, expérience, formation et compétences
- Typographies Google Fonts (DM Serif Display, DM Sans, JetBrains Mono)

## 📁 Structure
```
portfolio/
├── index.html    # structure et contenu
├── style.css     # styles et thèmes
├── script.js     # interactions
└── assets/       # images
```

## 🚀 Lancer en local
Ouvrir `index.html` dans un navigateur, ou :
```bash
python -m http.server 8000   # puis http://localhost:8000
```
